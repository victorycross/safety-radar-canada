# CLAUDE.md -- Safety Radar Canada

## Project Context
- **Name:** Safety Radar Canada
- **Purpose:** Canadian safety and compliance radar dashboard built with Lovable
- **Stack:** Vite, React, TypeScript, shadcn/ui, Tailwind CSS

## Commands
- **Dev:** `npm run dev`
- **Build:** `npm run build`
- **Lint:** `npm run lint`
- **Type check:** `npm run type-check`
- **Preview:** `npm run preview`

## Notes
- Lovable-generated project (https://lovable.dev).
- Uses shadcn/ui component library with Tailwind CSS.
